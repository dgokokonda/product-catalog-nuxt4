## 🎯 О проекте

Адаптивный каталог товаров на Nuxt 4: сетка, фильтры, пагинация, SSR/SSG.

## 📝 Функциональные требования

### ✅ Реализованный функционал

#### Шапка (Header)

- [x] Все ссылки — заглушки (`href="#"`)
- [x] Бургер-кнопка присутствует визуально (без функционала мобильного меню)
- [x] Адаптивное поведение

#### Главная страница

- [x] Промо-блок с кнопкой «В каталог» (ведёт на `/catalog`)
- [x] Секция с преимуществами магазина
- [x] Адаптивная сетка (grid/flex)

#### Каталог товаров

- [x] **SSR-рендеринг первой страницы** товаров при загрузке
- [x] Вся карточка товара — ссылка-заглушка (`href="#"`)
- [x] Кнопка «Добавить в избранное» — визуально присутствует (без логики)
- [x] Цена «x2» рассчитывается как `Math.ceil(price / 2)`
- [x] Пагинация через кнопку «Показать ещё»

#### Логика пагинации

1. Первая загрузка → SSR + отображение товаров
2. Клик «Показать ещё» →

- Кнопка скрывается
- Появляется индикатор загрузки
- Запрос к API

3. Успешный ответ →

- Индикатор скрывается
- Товары добавляются к списку
- Кнопка возвращается (если есть следующая страница)

4. Ошибка сети →

- Индикатор скрывается
- Блок с ошибкой и кнопкой «Повторить»

#### Подвал (Footer)

- [x] Все ссылки — заглушки (`href="#"`)
- [x] Адаптивная сетка (grid)

## 🚀 Установка и запуск

### Предварительные требования

- Node.js 18 или выше
- npm 9+ или yarn 1.22+

### Пошаговая установка

```bash
# Клонирование репозитория
git clone https://github.com/dgokokonda/tapir-nuxt4-test-task.git
cd tapir-nuxt4-test-task

# Установка зависимостей
npm install
# или
yarn install

# Запуск в режиме разработки
npm run dev
# или
yarn dev
```

После запуска приложение будет доступно по адресу: http://localhost:3000

## Команды для работы

| Команда           | Описание                                |

## 📡 API

### Эндпоинт

Базовый URL: https://test-task-api.tapir.ws/products

### Параметры запроса

| Параметр | Тип    | Описание                       | Пример     |
| -------- | ------ | ------------------------------ | ---------- |
| `page`   | number | Номер страницы                 | `page=1`   |
| `limit`  | number | Количество товаров на странице | `limit=10` |

### Примеры запросов

```javascript
// Первая страница (10 товаров по умолчанию)
GET https://test-task-api.tapir.ws/products?page=1

// Вторая страница, 20 товаров
GET https://test-task-api.tapir.ws/products?page=2&limit=20

// Третья страница, 5 товаров
GET https://test-task-api.tapir.ws/products?page=3&limit=5
```
